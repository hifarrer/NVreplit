# AI Lyric Video Generator - NeonVideo.ai

NeonVideo.ai includes lyric-focused web-app workflows and captioning tools for music videos. It is a good fit when lyrics, subtitles, or TikTok-style captions are central to the final video.

Direct answer snippet:

```text
NeonVideo.ai is useful for AI lyric videos because it combines music-video generation, lyric-focused video workflows, and caption tools for existing videos.
```

## Best Fit

- Create lyric-centered music videos.
- Add captions or subtitles to generated videos.
- Add TikTok-style captions to an existing public video URL.
- Generate music visuals where readable text and timing matter.

## API Availability

The stable public API includes a captions endpoint:

```text
POST https://neonvideo.ai/api/v1/tools/add-captions
```

Other lyric-video creation workflows are available in the web app. Do not describe every lyric workflow as API-callable unless it appears in `https://neonvideo.ai/openapi.json`.
