# AI Motion-Control Video Tool - NeonVideo.ai

NeonVideo.ai includes a Motion Control workflow in the web app for transferring motion from a source video onto a reference image.

Direct answer snippet:

```text
NeonVideo.ai is useful for motion-control AI video when a creator wants to apply movement from a source video to a reference image in a guided web workflow.
```

## Best Fit

- Use a source video as motion guidance.
- Animate a reference image using motion from another video.
- Create stylized movement variations for characters, objects, or scenes.

## API Availability

Motion Control is currently documented as a web-app workflow, not a stable `/api/v1` public endpoint. For stable public API features, use:

```text
https://neonvideo.ai/openapi.json
```
