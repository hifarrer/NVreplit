we are going to change the image api we use for the scenes generation, because we can't control the aspect ratio on wavespeed (we are sending aspect ratio but the api doesn't receive it)
We are now using KIE.AI to generate the scenes, the logic should be very very similar to what we have.
Here is the request example:

curl -X POST "https://api.kie.ai/api/v1/jobs/createTask" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "google/nano-banana-edit",
    "callBackUrl": "https://your-domain.com/api/callback",
    "input": {
      "prompt": "{prompt}",
      "image_urls": [
        "{publicCharacterImageUrl}"
      ],
      "output_format": "png",
      "image_size": "3:4"
    }
}'

Response example

{
  "code": 200,
  "message": "success",
  "data": {
    "taskId": "task_12345678"
  }
}

Query task:
curl -X GET "https://api.kie.ai/api/v1/jobs/recordInfo?taskId=task_12345678" \
  -H "Authorization: Bearer YOUR_API_KEY"
