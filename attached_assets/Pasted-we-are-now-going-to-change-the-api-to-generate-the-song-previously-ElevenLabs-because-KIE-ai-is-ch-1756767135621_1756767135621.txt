we are now going to change the api to generate the song (previously ElevenLabs) because KIE.ai is cheaper and better.

Sample request:
curl --request POST \
  --url https://api.kie.ai/api/v1/generate \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "prompt": "{lyrics}",
  "style": "{tags}",
  "title": "{description}",
  "customMode": true,
  "instrumental": true,
  "model": "V4",
  "callBackUrl": "https://api.example.com/callback",
  "negativeTags": "",
  "vocalGender": "m",
  "styleWeight": 0.65,
  "weirdnessConstraint": 0.65,
  "audioWeight": 0.65
}'

Sample response:
{
  "code": 200,
  "msg": "success",
  "data": {
    "taskId": "5c79****be8e"
  }
}

To get results:
curl --request GET \
  --url https://api.kie.ai/api/v1/generate/record-info \
  --header 'Authorization: Bearer <token>'
Query Parameters
taskId  string
